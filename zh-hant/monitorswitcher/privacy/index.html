隱私權政策

最後更新：2026-10-25

MonitorSwitcher（以下稱「本應用程式」）由 Peachbit 提供，透過視訊線上的通訊通道 DDC/CI，切換連接到您電腦的顯示器的輸入、亮度與音量。

  1. 不收集任何資訊。 本應用程式不收集任何資訊，無論是否能識別個人身分，例如姓名、電子郵件地址、位置、使用情況或當機報告。
  2. 本應用程式本身不進行網路通訊。 本應用程式不連線至網際網路或任何伺服器，也不包含廣告、分析工具或第三方 SDK。試用期剩餘天數、購買狀態的確認及購買手續，由 Windows 內建的 Microsoft Store 服務處理，並遵循 Microsoft 隱私權聲明。使用兌換碼時，會在瀏覽器中開啟 Microsoft 的代碼兌換頁面。
  3. 僅儲存在您的電腦中。 設定（顯示語言、佈景主題、輸入名稱、快速鍵、預設組合等）與運作記錄，僅儲存在本機上本應用程式專用的資料夾中，不會傳送到外部，解除安裝本應用程式時會一併刪除。
  4. 與顯示器的通訊。 本應用程式與顯示器之間的通訊，僅限於讀取與變更輸入、亮度與音量，以及讀取顯示器的型號名稱與支援的功能。
  5. 聯絡方式。 如對本政策有任何疑問，請聯絡 peachbitsoft@outlook.com（Peachbit）。
