MonitorSwitcher
隐私政策

最后更新：2026-10-25

MonitorSwitcher（以下称“本应用”）由 Peachbit 提供，通过视频线上的通信通道 DDC/CI，切换连接到您电脑的显示器的输入、亮度和音量。

  1. 不收集任何信息。 本应用不收集任何信息，无论是否能识别个人身份，例如姓名、电子邮件地址、位置、使用情况或崩溃报告。
  2. 本应用自身不进行网络通信。 本应用不连接互联网或任何服务器，也不包含广告、分析工具或第三方 SDK。试用期剩余天数、购买状态的确认以及购买手续，由 Windows 内置的 Microsoft Store 服务处理，并遵循 Microsoft 隐私声明。使用兑换码时，会在浏览器中打开 Microsoft 的代码兑换页面。
  3. 仅保存在您的电脑中。 设置（显示语言、主题、输入名称、快捷键、场景预设等）和运行日志仅保存在本机上本应用专用的文件夹中，不会被发送到外部，卸载本应用时会被删除。
  4. 与显示器的通信。 本应用与显示器之间的通信，仅限于读取和更改输入、亮度和音量，以及读取显示器的型号名称和支持的功能。
  5. 联系方式。 如对本政策有任何疑问，请联系 peachbitsoft@outlook.com（Peachbit）。
